# DataFlow 白皮书原型说明

## 文件

- `whitepaper-workbench.html`：单页静态原型，包含“工作台 / 报表数据集 / 模板编辑器”三个视图。

## 当前交互

- 工作台：生成报告、编辑模板、模板校验、导入模板可打开模拟弹窗。
- 报表数据集：可切换主表、搜索表、新增关联、筛选、维度、指标配置；可删除配置芯片；可运行预览、校验 SQL；可切换图表类型；可切换图表预览、数据结果、生成 SQL；可增删 X 轴、Y 轴、图例字段槽；可修改图表标题和展示设置；可保存数据集。
- 报表数据集整改：主表、字段面板、JOIN、WHERE、GROUP BY、METRICS、SQL、结果表、图表字段槽和保存校验改为同一份页面状态驱动；切换主表会刷新可用字段并重置不兼容配置；保存前会校验图表类型和字段槽要求。
- 模板编辑器：顶部改为 Word 风格富文本工具栏，覆盖剪贴板、字体、字符格式、段落、样式、插入、审阅和输出；右侧报表数据集支持拖拽到 Word 文档指定位置插入；可刷新报表块、校验模板、模拟导出 Word。

## 产品边界

白皮书第一版按“模板生成报告 + 生成后可编辑”设计，不直接集成 Metabase、Superset、Tableau 或 Power BI。

核心能力：

- 运维人员配置报表数据集：选数据源、选表、关联、筛选、分组、聚合、图表样式。
- 模板维护人员编辑白皮书模板：章节、正文、报表块、生成参数。
- 业务或管理用户查看生成记录，导出 Word / PDF。

## 参考产品取舍

- Metabase：参考“选数据、关联、筛选、汇总分组、可视化”的低门槛 Query Builder。
- Superset：参考 Metrics、Group By、Time Grain、Customize 的图表配置面板。
- Power BI：参考字段槽位和右侧图表配置面板。
- Tableau：只参考维度、指标、筛选、视觉通道概念，不照搬专业 BI 工作台。
