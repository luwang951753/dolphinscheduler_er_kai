# 字段映射设计

## 目标

让用户从源表字段中自由选择需要同步的字段，并设计目标表字段。字段映射区要清楚展示源字段和目标字段之间的对应关系。

当前确认设计以 `../prototype/field-mapping-workbench-v4.html` 为准。该原型已经确认：表格编辑为主，连线表达来源；虚线代表系统自动映射，实线代表用户手动拖拽映射。

## 源字段区

源字段必须展示：

- 同步复选框
- 字段名
- 源字段类型
- 字段注释
- 是否主键
- 是否允许为空

列顺序固定为：

1. 同步
2. 源字段
3. 源类型
4. 字段注释

主键、非空、可空标签应内联展示在源字段名后方，不要放在字段名下面。

交互必须支持：

- 全选
- 反选
- 清空
- 只看异常
- 只勾选部分字段

## 目标字段设计区

目标字段必须支持：

- 字段名可编辑
- 目标类型可选择
- 字段注释可编辑
- 主键可设置
- 可空可设置

目标字段的默认类型应根据目标库类型自动推荐，例如 MySQL 到 PostgreSQL 时要做类型映射。

目标字段区列顺序固定为：

1. 目标字段
2. 目标类型
3. 字段注释
4. 主键
5. 可空

目标字段区不再展示重复“字段名”列，不展示“来自 xx”“当前来源”“映射方式”等冗余文案。来源关系通过连线表达。

新建目标表模式下，目标字段名支持三种批量规则：

- 保持源名
- 全小写
- 全大写

## 连线映射

字段映射可以通过拖拽连线表达：

- 左侧源字段有连接点。
- 右侧目标字段有连接点。
- 所有源字段和目标字段都应有连接点，包括未映射字段。
- 用户可以从左侧源字段连接点拖到右侧目标字段。
- 用户也可以从右侧目标字段连接点反向拖回左侧源字段。
- 不应只允许拖到很小的圆点，字段头部区域也应可作为有效落点。
- 连线即使发生交叉，也必须保持可见，不能被左右字段面板遮挡。
- 自动映射使用虚线。
- 手动拖拽映射使用实线。
- 页面需要展示虚线和实线的含义。
- 一个源字段可以映射到多个目标字段。
- 一个目标字段同一时刻只能有一个来源。
- 拖拽建立映射前必须校验类型兼容性；目标类型不能安全承接源类型时，不建立连线并提示原因。
- 映射关系调整后，配置生成和 DDL 生成必须使用最新映射。

## 历史问题

- 源字段无法勾选。
- 源字段类型显示为 `unknown`。
- 第 2 步虽然有全选/反选，但无法只勾选部分字段。
- 目标字段区曾出现不必要的全选、全不选、反选按钮。
- 拖拽连线后曾出现 `id` 和 `ajbh` 对应关系互换，需要重点回归。
