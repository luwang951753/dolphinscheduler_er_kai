## 当前阻塞与风险

1. `actuator/health` 当前返回 `DOWN`，但登录和业务 API 可用。需要后续单独排查健康检查依赖项。
2. 演示库 `case_workbench.ajxx_tab.status` 查询出来存在中文乱码现象，会影响中文枚举规则测试。建议重建 fixture 时显式使用 `utf8mb4`。
3. 单模块 `dolphinscheduler-api` Maven 编译会因为本地新增 DAO 类未进入依赖 jar 而失败；完整 `-am compile` 可编译，但很慢。后续应把 DAO jar 正式打包并同步到 standalone，避免运行态和编译态不一致。
4. 主题库目前还未进入正式产品化开发，不能按正式功能验收。
