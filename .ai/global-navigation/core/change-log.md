# 全局导航变更记录

## 2026-05-16 顶栏低频设置收纳到用户菜单

- 背景：
  - 用户反馈 Dolphin 顶栏右侧“界面设置、深色/浅色、中文、时区设置”使用频率不高，常驻展示挤占顶部主菜单空间，导致其他模块名称显示不完整。
- 设计决策：
  - 顶栏只保留 Logo、主菜单和最右侧用户名下拉。
  - 将界面设置、主题切换、语言切换、时区设置统一归入用户名下拉菜单的“偏好设置”区。
  - 原有用户信息、密码管理、产品信息、退出登录继续保留在用户名下拉菜单内。
- 验收标准：
  - 顶栏右侧不再直接展示“界面设置、深色/浅色、中文、Asia/Shanghai”等低频项。
  - 点击用户名下拉后能看到并操作界面设置、主题、语言、时区。
  - 主菜单区域获得更多宽度，同步任务、数据预览等菜单名称更容易完整展示。
