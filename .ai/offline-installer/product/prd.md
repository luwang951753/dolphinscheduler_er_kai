# 离线安装向导 PRD

## 1. 用户角色

| 角色 | 诉求 |
|------|------|
| 实施同事 | 不懂 Dolphin 配置文件，也能完成安装 |
| 运维同事 | 能看到端口、数据库、目录权限等检查结果 |
| 开发维护者 | 安装配置可追踪、可回滚、可复现 |

## 2. 核心体验

安装体验应接近成熟产品的首次安装向导：

1. 终端只负责启动安装器。
2. 浏览器负责填写配置、检测、预览、安装。
3. 页面用状态卡明确告诉用户“哪些通过、哪些失败、下一步做什么”。
4. 安装完成后直接给正式访问地址和启停命令。

## 3. 页面信息架构

页面采用左侧步骤导航、右侧配置表单和底部操作区。

左侧步骤：

1. 环境检查
2. 数据库配置
3. 服务配置
4. 同步运行配置
5. 预览与安装

顶部展示：

- 产品名：DolphinScheduler 离线安装向导
- 当前安装包版本：3.4.1-公司二开版
- 安装模式：Standalone
- 安装状态：未安装 / 检测中 / 可安装 / 安装完成

## 4. 字段设计

### 4.1 环境检查

| 字段 | 默认值 | 说明 |
|------|--------|------|
| JDK 路径 | 自动识别 `JAVA_HOME` | 必须是 1.8 |
| 安装目录 | 当前 standalone 根目录 | 只读展示 |
| Dolphin 端口 | 12345 | 检查端口是否占用 |
| 写入权限 | 自动检测 | 检查 conf、logs、backup |

说明：安装向导自身端口属于临时启动信息，不在环境检查表单中展示，避免和 Dolphin 服务端口混淆。若安装向导端口冲突，应由 `install-web.sh` 在终端提示用户更换启动端口。

### 4.2 数据库配置

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 数据库类型 | MySQL | 第一版固定 MySQL |
| 主机 | 127.0.0.1 | 公司内网 MySQL 地址 |
| 端口 | 3306 | MySQL 端口 |
| 库名 | dolphinscheduler | Dolphin 元数据库 |
| 用户名 | 空 | MySQL 用户 |
| 密码 | 空 | 页面脱敏 |
| 初始化数据库 | 默认开启 | 首次安装导入 SQL |

### 4.3 服务配置

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 访问地址 | `http://服务器IP:12345/dolphinscheduler/ui` | 安装完成后展示 |
| API 地址 | `http://服务器IP:12345/dolphinscheduler` | 写入 base-url |
| 日志目录 | `./logs` | 可自定义绝对路径 |
| 资源目录 | `./data/resource` | 本地资源存储路径 |
| 时区 | Asia/Shanghai | 默认中国时区 |

### 4.4 同步运行配置

| 字段 | 默认值 | 说明 |
|------|--------|------|
| SeaTunnel Home | 空 | 同步任务执行组件路径 |
| 临时目录 | `./data/sync/tmp` | 生成配置、临时脚本 |
| 任务日志目录 | `./logs/sync-task` | 同步任务执行日志 |
| JDBC 驱动目录 | `./libs` | 离线驱动 jar 目录 |

### 4.5 预览与安装

展示将写入的配置文件，采用文件选项卡 + 单文件代码查看器：

- `application.yaml`
- `common.properties`
- `dolphinscheduler_env.sh`

交互要求：

- 默认展示 `application.yaml`。
- 用户点击某个文件选项卡后，只展示该文件的完整预览内容。
- 文件选项卡展示文件名、写入路径、风险等级和变更项数量。
- 代码查看器固定高度并支持滚动，适配配置文件内容很多的情况。
- 文件内容需要使用等宽字体和深色代码块，提高配置阅读效率。

密码显示为 `******`。

## 5. 交互规则

1. 每一步必须可以“检测当前步骤”。
2. 未通过检测不能进入最终安装。
3. 数据库连接测试通过后才允许初始化数据库。
4. 点击“开始安装”后显示实时步骤：
   - 备份配置
   - 写入配置
   - 初始化数据库
   - 启动 DolphinScheduler
   - 健康检查
5. 安装完成后展示：
   - 访问地址
   - 默认账号提示
   - 启动命令
   - 停止命令
   - 日志路径

## 6. 错误处理

| 错误 | 页面提示 |
|------|----------|
| JDK 不是 1.8 | 当前版本要求 JDK 1.8，请切换 JAVA_HOME |
| MySQL 连接失败 | 展示主机、端口、库名和错误摘要，不展示密码 |
| 端口占用 | 展示占用端口和建议替换端口 |
| 配置文件无写权限 | 展示具体文件路径和 chmod 建议 |
| 初始化 SQL 失败 | 展示失败 SQL 文件和错误摘要 |
| 启动超时 | 展示日志路径和最后 50 行日志入口 |
