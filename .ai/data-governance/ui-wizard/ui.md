# 数据治理 UI 原型说明

## 1. 页面路由

建议路由：

- `/ui/data-governance`

建议菜单：

- 数据治理

入口放在“数据预览”右侧或附近，与“同步任务”“数据预览”组成数据相关能力组。

## 2. 原型目标

第一版原型做成单页工作台：

- 顶部：指标概览 + 搜索
- 左侧：治理导航和筛选
- 中间：资产目录
- 右侧：资产详情

这样用户一眼能看到资产列表、质量状态、血缘和问题，不需要在多个页面来回跳。

## 3. 页面布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 数据治理 / 搜索资产 / 新建质量规则 / 刷新元数据                 │
├──────────────────────────────────────────────────────────────┤
│ 指标：资产总数 / 有 Owner / 质量通过率 / 血缘 / 待处理问题       │
├───────────────┬───────────────────────────────┬──────────────┤
│ 左侧筛选       │ 资产目录表格                    │ 资产详情      │
│ 数据源类型     │ 资产 / 标签 / Owner / 质量       │ 概览          │
│ 标签           │ 最近同步任务 / 最近检测          │ 字段          │
│ 质量状态       │                               │ 质量          │
│ 是否有血缘     │                               │ 血缘          │
│ 问题状态       │                               │ 问题          │
└───────────────┴───────────────────────────────┴──────────────┘
```

## 4. 资产目录交互

- 点击资产行，右侧详情面板更新。
- 点击标签筛选，对资产列表过滤。
- 点击质量状态，进入质量模块。
- 点击血缘数量，详情面板切换到血缘 Tab。
- 点击最近同步任务，跳转到同步任务详情。

## 5. 资产详情交互

详情面板 Tab：

1. 概览
2. 字段
3. 质量
4. 血缘
5. 问题

字段 Tab：

- 字段表格显示字段名、类型、注释、主键、可空、标签。
- 敏感字段用标签标识，不做强权限拦截。

质量 Tab：

- 展示规则列表。
- 支持新增规则按钮。
- 第一版原型展示配置抽屉，不做真实执行。

血缘 Tab：

- 展示轻量上游/当前/下游关系。
- 优先展示由同步任务生成的血缘。

问题 Tab：

- 展示质量异常和人工问题。
- 支持切换状态。

## 6. 设计禁止项

- 不做全屏大屏风格。
- 不做复杂关系图作为第一屏主体。
- 不做 iframe 嵌入外部治理系统。
- 不在第一版引入外部组件依赖。
