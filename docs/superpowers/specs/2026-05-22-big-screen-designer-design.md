# 大屏设计器 V2 成熟 MVP 设计说明

日期：2026-05-22

## 背景

当前大屏设计器原型已经能从空白画布拖组件、绑定主题库 SQL 数据块、执行模拟预览、字段映射、保存布局和预览模式。但它仍偏向“业务看板编辑器”，距离成熟大屏设计产品还有明显差距：左侧缺少组件库 / 图层 / 数据 / 模板分区，画布元素模型不完整，数据直接绑定 SQL，缺少数据集层，右侧配置层级不足，也缺少发布、版本、权限、筛选和联动等成熟产品入口。

本设计用于 V2 独立 HTML 原型，不改 DolphinScheduler 二开代码。V2 目标不是一次性做生产级平台，而是在原型中把成熟产品的核心模型和可体验交互做出来，避免后续二开走偏。

## 产品定位

大屏设计器是一个独立的可视化搭建工具，用户从空白画布开始，通过组件库拖拽元素，绑定数据集，配置字段和样式，保存草稿，预览并发布大屏。

主题库 SQL 页面只作为模板案例或数据来源，不应绑死设计器结构。

## V2 成功标准

- 左侧是成熟设计器面板，不是单一页面大纲。
- 中间是真正元素化画布，不是固定业务页面预览。
- 每个画布元素都有统一模型：位置、尺寸、层级、锁定、显示、数据绑定、样式和交互。
- 数据绑定从“组件直接绑 SQL”升级为“数据源 -> 数据集 -> 字段 -> 组件”。
- 右侧配置按基础、数据、字段、样式、交互拆分。
- 用户可以拖组件、选中、移动、缩放、锁定、隐藏、复制、删除、调整层级。
- 用户可以选择数据集、切换图表展示方式、执行模拟预览、配置字段映射。
- 用户可以保存草稿、加载草稿、进入预览、查看发布/版本/权限入口。

## 数据流

```text
组件库拖入画布
  -> 生成画布元素
  -> 用户选择数据集或手写 SQL 创建数据集
  -> 执行模拟预览
  -> 生成字段列表
  -> 用户做字段映射
  -> 组件按展示方式渲染
  -> 保存草稿到 localStorage
  -> 预览 / 发布入口
```

## 图表配置

V2 至少支持以下展示方式：

- 指标卡：主指标、副指标、趋势字段
- 折线图：X 轴、Y 轴、系列字段、聚合、排序
- 柱状图：X 轴、Y 轴、排序、最大条数
- 饼图：分类字段、数值字段、最大分类数
- 表格：展示列、排序字段、最大行数
- 筛选器：筛选字段、默认值、目标组件

字段映射必须真实影响组件展示。

## 视觉设计能力

V2 原型需要体现大屏产品感，不只是后台表单：

- 画布背景配置入口
- 主题皮肤入口
- 大屏模板入口
- 装饰组件
- 科技风容器
- 分辨率预设
- 适配策略入口

第一版可以用静态选项和 mock 效果，不做复杂主题市场。

## 生命周期能力

V2 顶部需要体现：

- 保存草稿：localStorage
- 发布：弹窗提示发布成功并生成播放地址占位
- 版本历史：弹窗展示 2-3 条版本记录
- 权限：弹窗展示查看/编辑权限配置占位
- 分享：弹窗展示分享链接占位
- 全屏播放：进入预览模式

## 筛选与联动

V2 支持最小闭环：

- 时间筛选器组件
- 下拉筛选器组件
- 筛选器选择目标组件
- 改变筛选值后，目标组件显示“已接收参数”提示或刷新 mock 数据

## 非目标

V2 不做：

- 真实数据库查询
- 真实权限校验
- 后端保存
- 多人协同
- 完整撤销重做栈
- 复杂多选框选
- 真实地图底图
- DolphinScheduler 菜单集成
