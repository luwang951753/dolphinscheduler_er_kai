# 同步任务 Agent 需求文档

## 1. 背景

当前“同步任务”已经可以通过页面向导完成数据源、库表、字段映射、过滤、数据去向、执行与调度配置。但这个过程仍然要求使用者理解数据源、Schema、字段映射、SeaTunnel 配置和 DolphinScheduler 工作流，对非专业同事不够友好。

本阶段新增“同步任务 Agent”，目标是让用户用自然语言描述同步诉求，系统自动解析意图、匹配元数据、填充同步任务向导，并可继续保存或立即执行。

## 2. 成熟产品参考

- DataWorks Copilot / 数据集成：通过自然语言辅助创建数据同步任务，核心价值是降低任务配置门槛，但最终仍要落到数据来源、数据处理、数据去向和字段映射的结构化配置。
- Informatica CLAIRE Copilot：面向数据集成管道，使用自然语言生成管道草稿、解释配置和辅助排错，强调“可审阅、可修改、可执行”。
- Airbyte Connector Builder AI：通过描述和样例辅助配置连接器，但仍保留连接、字段、同步模式等结构化审阅入口。

本模块采用这些产品的共同模式：Agent 负责把用户意图转换为结构化草稿，人仍可以审阅关键配置；当用户明确要求“立即执行”时，Agent 可以继续触发保存并运行。

## 3. 核心目标

1. 用户在“同步任务”列表页点击“Agent 创建同步任务”。
2. 用户输入自然语言，例如：
   - “把 mysql case_workbench.ajxx_tab 同步到 pg public.agent_ajxx_tab，只同步5条”
   - “将 MySQL case_workbench.ajxx_tab 同步到 PostgreSQL public.agent_sync_test，字段自动映射并立即执行”
3. Agent 自动解析源端数据库类型、库名、表名、目标端数据库类型、目标 Schema、目标表、条数限制和是否立即执行。
4. Agent 自动匹配现有 Dolphin 数据源、项目、库表和字段。
5. Agent 自动填充四步向导，并在第 2 步展示字段映射、源端过滤和数据去向。
6. 如果用户选择确认执行，系统复用现有保存和运行流程创建 DolphinScheduler 工作流并启动实例。

## 4. MVP 范围

### 4.1 必须支持

- 在 `/sync-task` 列表页提供 Agent 入口。
- 在抽屉中展示用户输入、解析结果、执行进度和风险提示。
- 支持 MySQL、PostgreSQL、Oracle、Doris 关键词识别。
- 支持 `库.表`、`schema.表`、`public.表`、`目标表 xxx` 等常见表达。
- 支持“只同步 N 条 / 前 N 条 / limit N”的抽样意图。
- 自动选择第一个可用项目，用户也可以在向导中继续修改。
- 优先选择类型匹配的数据源；如果名称也匹配则优先使用名称匹配的数据源。
- 自动加载源端库表字段。
- 新建目标表场景下，按源字段自动生成目标字段，默认全选并自动映射。
- 生成 Agent 计划卡片，展示配置摘要、置信度、风险和下一步动作。
- “套用到向导”后跳转到同步任务向导第 2 步，让用户看到字段映射结果。
- “确认并执行”复用现有 `handleRunWorkflow`。

### 4.2 暂不支持

- 不依赖外部大模型服务，先使用本地确定性解析器，避免内网部署不可用。
- 不强制引入 Milvus。Milvus 用于二期做元数据语义召回、历史任务推荐和字段注释理解。
- 不支持复杂 SQL 自由生成，避免注入和不可审阅风险。
- 不支持多表批量同步；多表任务属于后续能力。

## 5. 解析与匹配规则

1. 数据源类型识别：
   - `mysql`、`MySQL` -> `MYSQL`
   - `pg`、`pgsql`、`postgres`、`postgresql` -> `POSTGRESQL`
   - `oracle` -> `ORACLE`
   - `doris` -> `DORIS`
2. 表路径识别：
   - 第一个 `库.表` 默认作为源端。
   - “到 / 至 / 写入 / 同步到”之后的 `schema.表` 默认作为目标端。
   - 目标端为 PostgreSQL / Oracle 时，`public.xxx` 识别为 Schema + 表名。
3. 条数限制识别：
   - `只同步5条`、`前 5 条`、`limit 5` 识别为 `limit = 5`。
4. 执行动作识别：
   - 包含“立即执行 / 执行 / 跑起来 / 启动”时，默认勾选自动执行意图。
5. 元数据匹配：
   - 先按数据源类型过滤。
   - 再按自然语言中的数据源名称片段匹配。
   - 再按库名、表名加载真实元数据。

## 6. 风险与提示

- 未找到匹配数据源：提示用户先在 Dolphin 数据源管理中创建连接。
- 未找到源库或源表：展示无法自动匹配的路径，并允许用户进入向导手动调整。
- 字段加载失败：Agent 不执行保存或运行，只停留在向导第 1 步。
- 目标表已存在：进入已有目标表映射模式，按现有字段名自动匹配。
- 目标表不存在：按源字段生成目标表字段。
- 解析置信度低于 70%：默认只允许“套用到向导”，不自动执行。

## 7. 二期方向

- 接入本地大模型或公司内网模型，用于更复杂的意图理解。
- 接入 Milvus，将数据源、库表、字段注释、历史同步任务写入向量库，支持“把案件表同步到分析库”这类模糊描述。
- 支持多表任务、调度表达、失败诊断和自动修复建议。
