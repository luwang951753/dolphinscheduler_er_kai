# 数据预览手写 SQL 查询设计说明

日期：2026-05-20

## 背景

当前“数据预览”支持结构化 WHERE、ORDER BY、字段显隐、关联和表结构查看，但一些排查场景仍需要手写 SQL：

- 临时 Join 多张表排查数据问题。
- 使用聚合函数做行数、状态分布、异常值统计。
- 复制开发或运维已有 SQL 快速验证。
- 对比筛选器无法表达的复杂条件。

该能力风险较高，因此首期定位为“只读 SQL 查询控制台”，不是完整 SQL IDE，也不是数据库管理平台。

## 成熟产品参考

### DataGrip

DataGrip 通过 Database Console / Query Console 连接当前数据源，在上方编辑 SQL，下方展示结果集、消息和执行计划。适合参考其“上下分区 SQL 控制台”形态。

### DBeaver / CloudBeaver

DBeaver 的 SQL Editor 支持 SQL 编辑、执行当前语句、执行脚本、结果集、执行历史和 Explain Plan。适合参考其“编辑器 + 结果集 + 历史”的工作流。

### Navicat

Navicat 提供 Query Editor 和 Query Builder，支持保存查询、执行 SQL、查看结果。适合参考其“查询作为独立工作对象”的组织方式。

### 阿里云 DMS

DMS 的 SQL 窗口强调权限、安全规则、执行审计和结果限制。适合参考其“生产环境 SQL 必须受控”的安全设计。

## 设计结论

在“数据预览”中新增一个与“数据预览 / 表结构 / DDL / 索引约束”平级的页签：

- SQL查询

该页签不替代原有结构化筛选。普通用户仍优先使用数据预览和 WHERE/ORDER BY 条件条；只有复杂排查时进入 SQL 查询。

## 页面结构

SQL 查询页采用成熟数据库工具常见的上下分区：

上半区：

- 当前连接上下文
- SQL 编辑器
- 执行选中 / 当前语句
- 执行全部
- 执行计划
- 格式化
- 清空
- 只读、安全、超时、最大返回行提示
- 右侧执行历史

中间消息条：

- 校验提示
- 执行成功提示
- 安全拦截提示
- 自动 limit 提示

下半区：

- 结果集
- 消息
- 执行计划

## 安全边界

首期只允许：

- `SELECT`
- `WITH`
- `EXPLAIN`

首期禁止：

- `INSERT`
- `UPDATE`
- `DELETE`
- `DROP`
- `TRUNCATE`
- `ALTER`
- `CREATE`
- `GRANT`
- `REVOKE`
- `MERGE`
- `REPLACE`
- 存储过程调用
- 多语句任意脚本执行

后端必须做最终校验，不能只依赖前端校验。

## 执行策略

- 默认只读连接。
- 默认超时 30 秒。
- 默认返回 50 行，可选 100 / 200 行，最大 200 行。
- 用户 SQL 没有 limit 时，后端自动追加安全分页限制。
- 多语句默认不允许直接执行；只有“执行全部”入口可处理，并且仍必须逐条校验只读。
- SQL 执行必须记录审计信息：用户、数据源、库、SQL 摘要、执行时间、耗时、返回行数、失败原因。

## 与现有数据预览关系

SQL 查询不影响当前表的结构化视图配置：

- 不保存到普通个人视图。
- 不复用 WHERE/ORDER BY 条件条。
- 可使用当前数据源、数据库、表上下文生成默认 SELECT。
- 执行结果可以导出，但导出必须遵守当前用户权限和最大导出限制。

## 后续实现建议

后端新增 SQL 查询接口时，需要至少包含：

- 权限校验：用户是否有当前数据源查询权限。
- SQL 类型校验：只读白名单。
- 元数据校验：当前数据源和数据库必须来自用户可访问范围。
- 超时控制。
- 最大返回行数限制。
- 审计日志。
- 错误信息脱敏。

前端需要：

- SQL 编辑器组件。
- 结果集渲染。
- 执行历史列表。
- 安全提示。
- 执行计划结果展示。
- 错误状态展示。

## 测试点

正式开发后至少覆盖：

- SQL 查询页签可进入。
- 默认 SQL 根据当前表生成。
- 执行 SELECT 成功并展示结果集。
- 选中部分 SQL 后只执行选中语句。
- 无选中时执行当前编辑器 SQL。
- 禁止 UPDATE / DELETE / DROP / TRUNCATE / ALTER 等语句。
- 无 limit 时后端自动限制最大返回行数。
- 执行失败显示明确错误。
- 执行历史可加载回编辑器。
- 切换表后默认 SQL 更新。
- 执行计划可查看。
- 导出结果遵守当前结果集和权限。
- 原有数据预览、表结构、DDL、索引约束不回归。
