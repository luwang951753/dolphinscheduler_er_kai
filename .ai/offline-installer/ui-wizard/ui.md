# 离线安装向导 UI 设计

## 1. 设计基调

参考 Gitea / WordPress / Nextcloud 的首次安装向导，但视觉上保持 DolphinScheduler 管理后台风格：克制、清晰、表单密度适中，不做营销式大图。

## 2. 页面布局

```text
┌─────────────────────────────────────────────────────────────┐
│ DolphinScheduler 离线安装向导     Standalone / 3.4.1 二开版 │
├───────────────┬─────────────────────────────────────────────┤
│ 环境检查       │ 当前步骤标题                                  │
│ 数据库配置     │ 说明 / 状态卡                                  │
│ 服务配置       │ 表单                                          │
│ 同步运行配置   │ 检测结果                                      │
│ 预览与安装     │ 底部按钮                                      │
└───────────────┴─────────────────────────────────────────────┘
```

## 3. 步骤状态

| 状态 | 样式 |
|------|------|
| 未开始 | 灰色圆点 |
| 当前 | 蓝色高亮 |
| 通过 | 绿色对勾 |
| 失败 | 红色告警 |
| 安装中 | 蓝色进度 |

## 4. 关键交互

### 4.1 环境检查

页面进入后自动检测一次：

- JDK 版本
- Dolphin 服务端口占用
- conf 写权限
- 是否已安装

用户可点击“重新检测”。

安装向导服务端口不在页面表单中展示，只在启动脚本输出的安装 URL 中出现。页面避免同时出现“安装器端口”和“Dolphin 端口”，降低配置误解。

### 4.2 数据库配置

数据库表单右侧展示连接状态：

- 未检测
- 连接中
- 连接成功
- 连接失败

连接失败时展开错误摘要，不展示密码。

### 4.3 预览与安装

采用文件选项卡预览，避免多个大配置文件并排导致阅读困难：

- 左侧或顶部展示配置文件选项卡，包含文件名、写入路径和风险等级。
- 默认选中 `application.yaml`，用户点击任意文件选项卡后，右侧只展示当前文件内容。
- 文件内容使用大尺寸代码查看器展示，支持纵向滚动，长文件不撑高整个页面。
- 风险等级、变更项数量和写入路径固定显示在代码查看器顶部，便于安装前确认。

安装进度使用纵向 timeline：

1. 备份旧配置
2. 写入新配置
3. 初始化数据库
4. 启动服务
5. 健康检查
