# 同步任务页面 UI

## 页面路由

`/ui/sync-task`

## 页面入口

在 DolphinScheduler 菜单栏中，将“同步任务”插入到“源中心”右侧。入口要自然融入原有导航，不影响源中心和项目管理等原生功能。

## 四步向导

| 步骤 | 名称 | 目标 |
|------|------|------|
| 1 | 选择源与目标 | 选择项目、源数据源、源库表、目标源和目标表 |
| 2 | 配置同步方案 | 配置字段映射、源端过滤、数据去向和预留数据处理 |
| 3 | 执行与调度 | 建表预览、确认建表、配置运行方式 |
| 4 | 预览与发布 | 检查配置，保存任务，保存并执行 |

## 交互要求

- 第 3 步和第 4 步必须能正常切换，不能因为前置校验写死导致无法进入。
- 配置周期调度不应强制要求源、目标、字段映射都已配置完成。
- “查看配置预览”应是全局单一浮层，支持查看和编辑，不要每一步重复展示。
- 页面不要出现冗余标题，例如每步内部再显示“第 1 步、第 2 步”这类无意义文案。
- 文本不能竖排，空状态和无内容状态要有稳定宽度。
- 第 1 步只负责选择源与目标，不展示源端过滤条件、字段映射、数据去向或数据处理配置。
- 第 1 步采用已确认的源目标对照式工作台：基础信息区 + 源端卡片 + 中间“对象确认”节点 + 目标端卡片。
- 第 1 步不展示源表摘要、目标对象摘要、字段统计、主键数、可空字段数、表注释或预估行数。
- 第 1 步不展示“目标表模式”切换控件；目标表名填写后由系统自动判断目标表是否存在，并提示“将新建”或“使用已有表”。
- 第 2 步采用“配置同步方案”模块化工作台，左侧模块列表、右侧模块详情。
- 第 2 步模块顺序固定为：字段映射关系、源端过滤条件、数据去向、数据处理。
- 左侧模块列表不展示“1 映射 / 2 过滤 / 3 去向 / 4 处理”等重复编号。
- 源端过滤条件位于第 2 步，采用结构化条件行，不使用自由 SQL 编辑器作为主入口。
- 数据去向只保留“同步前 SQL（custom_sql）”，不展示写入策略配置入口，不使用 `preSql` 文案。
- 数据处理模块本期只保留入口，展示“暂未实现”，不参与保存、执行或配置生成。

## 视觉要求

- 借鉴 DataWorks、云厂商数据集成平台、大数据同步产品的向导式布局。
- 页面应有步骤条、同步对象工作台、配置校验提示和清晰操作按钮。
- 第 1 步源端与目标端卡片高度应按内容收起，不能出现大面积空白卡片。
- 源字段区、字段连线区、目标字段设计区要清晰分区。
- 字段映射可以通过拖拽连线表达，让用户更直观看到字段对应关系。

## 第 2 步字段映射 V4 原型基线

当前已确认原型：

- 文件：`../prototype/field-mapping-workbench-v4.html`
- 本地服务地址：`http://127.0.0.1:8026/field-mapping-workbench-v4.html`
- 原型标记：`V4 映射图例与源字段标签优化`

正式 Dolphin 页面实现必须对齐以下基线：

- 字段映射工作台必须组件化实现，不能用 iframe 嵌入原型页。
- 只复用字段映射工作台本体，不带入 V4 原型里的执行步骤大卡片和摘要大卡片。
- 源字段区列顺序：同步、源字段、源类型、字段注释。
- 源字段区按钮：全选、反选、清空、只看异常。
- 源字段的主键、非空、可空标签内联放在源字段名后面。
- 目标字段区列顺序：目标字段、目标类型、字段注释、主键、可空。
- 目标字段是输入框，允许修改。
- 目标类型是下拉框，允许选择目标端类型。
- 字段注释是输入框，允许修改。
- 主键、可空是逐行复选框。
- 不展示“来自 xx”“当前来源”“映射方式”。
- 不展示重复的“字段名”列。
- 新建目标表模式下，目标字段区提供“保持源名 / 全小写 / 全大写”，直接作用于目标字段输入框。
- 所有源字段和目标字段都显示连接点，包括未映射字段。
- 自动映射使用虚线，手动拖拽映射使用实线，并展示图例。
- 支持源到目标、目标到源的双向拖拽。
- 拖拽建立映射前必须校验字段类型兼容性。
- 第 4 步配置预览中应能看到源端过滤条件，便于用户确认不是全表同步。
